<intro>
This project is my case-study from my time at the Animation Workshop’s Creative Simulation Technologies course in Viborg, Denmark. The course was led by Andrew Lowell and sponsored by the European Union Creative Media program. If you are curious about the technical aspects of this project, I made UE Blueprint tutorials on <a href="https://youtu.be/zosX0RO0dBQ?feature=shared"> freehand splines</a> and <a href="https://youtu.be/fLV51V9FNdk?feature=shared"> Houdini Engine</a>.</intro>



<h3>Concept</h3>

I wanted to create a system for real-time graphics inspired by ecology: can an artist draw digital ‘organisms’ out of thin air? Can they exert influence over these organisms, imparting life and embedding them into an environment? In a future where media art is increasingly real-time and generative, can digital artists experience embodied creativity through procedural content generation (PCG)?

I prototyped a set-dressing toolset that allows artists to draw and manipulate real-time assets using freehand input, inspired by digital art tools like Procreate and Blender’s GreasePencil. I connected Unreal Engine’s brand new scriptable tools interface to Houdini Engine to create an embodied ecosystem for real-time PCG generation.  The system allow artists to create a game engine environment "by hand" without complicated UIs, overwhelming asset management, and other interrupters of flow.

While there isn't a physical component to this system (yet!), the  affirmation of embodiment informed the system's intent: for the artist to become a part of an organic virtual ecosystem, fully immersed in their craft.
